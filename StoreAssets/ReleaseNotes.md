# 패치 노트 (Play 콘솔 "이 버전의 새로운 기능", 짧게, 언어마다 500자 이하)

## 1.0.1 (버전 코드 4)

```
<ko-KR>
더 편하게 다듬었어요!
- 막히면 둘 수 있는 짝을 살짝 알려 줘요
- 덮인 패가 더 잘 보이고, 튜토리얼이 쉬워졌어요
- 뒤로 가기 나가기 창, 자리 비움 일시정지 추가
</ko-KR>
<en-US>
Smoother and easier to play!
- A gentle hint when you're stuck
- Clearer covered cards and an easier tutorial
- Quit prompt on back, auto pause when you switch apps
</en-US>
```

심사가 끝나 스토어에 1.0.1 이 나오면 `docs/app.json` 의 `latestVersion` 을 "1.0.1" 로 올려 푸시한다 (1.0.0 사용자에게 업데이트 창).
